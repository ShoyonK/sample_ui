# SiBench Station API: reference

Generated by `scripts/api/build.py` from `src/station_protocol/`; don't edit by hand. The rules (what each call does, state, activities, timeouts, events) are in [STATION_API.md](STATION_API.md); the same shapes as JSON Schema are in [station_api.schema.json](station_api.schema.json).

Every example is the exact JSON the fake station sends for the reference fixture, captured on a manual clock. Long lists and strings are shortened (`… N more`). Types are written short: `int 1..4` is an integer from 1 to 4, `X | null` may be null, a capitalised name is a type in [Types](#types).
